Tentang Aplikasi Ini

Aplikasi ini menggunakan teknologi WebRTC untuk menangkap tampilan layar Anda langsung di dalam browser.

  • Tidak ada perangkat lunak tambahan yang perlu diinstal.
  • Privasi terjaga: Layar Anda diproses secara lokal dan tidak dikirim ke server manapun kecuali Anda membagikannya melalui layanan pihak ketiga.
  • Anda dapat merekam sesi berbagi layar dan mengunduhnya dalam format WebM/MP4.

*Untuk berbagi dengan orang lain di perangkat berbeda, diperlukan integrasi server *signaling* (seperti WebSocket/Socket.io) yang tidak dapat dijalankan hanya dengan file HTML mandiri ini.
